# Compatibility name for the 2020–2024 ACS county data

An identical copy of `acs2020_2024_counties`, retained for existing
code. Each row is one county; values are Census period estimates for
2020–2024, not separate annual observations.

## Usage

``` r
data(acs2024_counties)
```

## Format

A data frame with 3,107 rows and 91 columns.
